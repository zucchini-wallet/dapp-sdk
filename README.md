# Zucchini Dapp SDK

Framework-independent TypeScript SDK for integrating applications with the Zucchini browser extension.

## Responsibilities

- Provider discovery and connection.
- Explicit permission requests.
- Address, balance, network, and transaction request contracts.
- ZIP 321 parsing and formatting.
- Compatibility fixtures and integration examples.

The SDK never handles wallet seeds, signing keys, wallet databases, or transaction proving.

## Status

Interface scaffold only. The first public release follows an adversarial review of the extension message bridge.
